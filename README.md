# 未来浏览器 — 轻量 iOS 浏览器（Flutter + WKWebView）

Flutter 3.47.x + webview_flutter 构建的 iOS 浏览器（工程名 NewWeb）。iOS 底层为系统 WKWebView，Flutter 提供壳 UI 与业务逻辑，Swift 原生层提供下载、内容拦截、中文菜单等系统能力。

- **目标系统**：iOS 15.0+
- **包名**：com.newweb.newweb
- **应用名**：未来浏览器

## 功能特性

### 浏览核心
- **多标签页**：最多 8 个，网格切换 / 关闭 / 新建，后台标签保活，标签页快照
- **手势导航**：左边缘右滑返回、右边缘左滑前进（与页面滚动共存）
- **上半屏下拉刷新**、前进 / 后退 / 刷新 / 首页 / 加载进度条
- **地址栏**：网址 / 搜索词自动识别，域名高亮，一键清空，搜索引擎切换
- **无痕模式**：不记录历史；退出无痕时清空全部网站数据
- **100% 汉化**：全部界面文案 + 系统组件中文本地化

### 网页翻译
- **整页翻译**：收集页面可见文本 → 翻译 → 按原文位置回填，可一键恢复原文
- **手动翻译**与**自动翻译**（自定义网址白名单，加载完成后自动触发）
- **在线 / 离线双模式**：在线走 Google → MyMemory → 腾讯云三级降级；离线走内置本地词库

### 下载管理
- 原生 URLSession 下载，支持**暂停 / 断点续传 / 取消**，落盘 Documents/Downloads
- 网页内点击常见文件后缀链接**自动接管下载**，下载完成弹窗提示
- 下载管理页：进行中任务 + 已完成列表（原生预览 / 分享 / 删除 / 完成时间）

### 广告拦截（原生 WKContentRuleList）
七大模块：
1. **资源拦截 block**：80+ 广告域名黑名单，正则 url-filter 匹配
2. **DOM 元素隐藏 css-display-none**：CSS 选择器隐藏同域投放广告
3. **Cookie 与追踪拦截 block-cookies**：拦截 GA / FB Pixel 等追踪器
4. **弹窗拦截**：拦截 popup 类型请求 + JS window.open 守卫
5. **DNS 层过滤**：生成 AdGuard DNS 配置描述文件，系统级域名解析拦截
6. **阅读器模式**：内置正文提取，原生阅读页渲染，字号可调
7. **反广告检测对抗**：豁免站点白名单，防止"请关闭广告拦截"提示
8. **自定义拦截规则**：用户可自行添加拦截域名，自动去 https:// 前缀和路径尾缀

### 缓存管理（四级）
- **L1 网页缓存**：沙盒 Caches 与网络缓存
- **L2 网络缓存**：WebView 磁盘缓存
- **L3 Cookie 与站点数据**：Cookie / localStorage / IndexedDB / WebSQL
- **L4 全部数据**：网站数据 + 离线页面 + 历史记录一键清空

### 密码本
- 本地存储网站登录账号密码，SQLite 加密
- 检测到登录表单自动提示填充
- 密码本管理页：添加 / 编辑 / 删除

### 其他
- 书签（添加 / 编辑 / 删除，SQLite 存储）、历史记录（自动记录 / 清空）
- 离线页面：整页保存，离线可读
- 网页截长图 / 导出 PDF / 查看源代码
- 手势灵敏度调节（边缘手势 + 下拉刷新独立调节）
- 检查更新 + 前台自动检测更新 + App 内下载 IPA 唤起全能签
- 全局调试日志（手机端可查看导出）

## 安装方式

1. 从 [Releases](https://github.com/lambret-1/newWeb/releases) 下载最新 `NewWeb.ipa`
2. 使用**全能签** / TrollStore / Sideloadly 等工具进行本地重签名安装
3. 无签名 IPA 不能直接安装，必须重签名

## CI/CD

- 生产构建：main 分支推送自动触发，版本自动递增（三段语义版本）
- PR 门禁：静态检查 + 编译校验，警告超阈值拦截
- 制品：未签名 IPA + SHA256 元数据 JSON，自动发布 Release
- 详细文档见 `docs/` 目录
